# Peach + Eggplant + Chili Premium 3D Theme

- 16:9 autoplay/muted/loop video
- Peach, eggplant and chili-inspired animated background
- Animated heart/logo
- Animated Video Call camera icon
- All Free Videos and Video Call buttons
- Sign Up to Access gate
- GitHub Pages ready

Put your own/authorized `video.mp4` in the root and replace `YOUR_SIGNUP_LINK` in `script.js`.
Browser autoplay is configured muted for compatibility.
A browser cannot guarantee a video can never be copied or screen-recorded; true DRM requires a DRM-capable service.
